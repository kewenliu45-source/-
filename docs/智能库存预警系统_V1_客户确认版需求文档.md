# 智能库存预警系统 V1.0 客户确认版需求文档

## 一、系统目标

智能库存预警系统通过销售数据、库存数据和总部库存数据自动分析库存风险，提前发现缺货、断码和库存积压问题，并提供调货建议，帮助门店提高库存周转效率、降低缺货损失和库存占压。

## 二、功能模块

### 1. 登录与用户管理

#### 登录

用户访问系统需先登录。登录成功后，方可使用系统功能。

#### 账号类型

管理员可使用全部功能：

- 库存预警
- 高库存预警

- 企业微信配置
- 用户管理
- 系统设置

普通用户可使用：

- 库存预警
- 高库存预警
- 查看分析结果
- 下载结果

普通用户不可使用：

- 用户管理
- 系统设置

#### 用户管理

管理员可进行以下操作：

- 新增用户
- 编辑用户
- 修改密码
- 禁用用户
- 删除用户

### 2. 低库存预警

#### 功能目标

系统用于提前发现：

- 已缺货商品
- 即将缺货商品
- 缺码商品

#### 数据来源

Excel 模式：

- 销售表
- 库存表
- 总部库存表
- 长周期到货表，可选

数据库模式：

系统自动读取：

- 销售数据
- 库存数据
- 在途库存数据

人工上传：

- 总部库存表
- 长周期到货表，可选

#### 预警类型

红色预警：

- 近期有销售
- 当前库存已经为 0
- 建议立即调货

黄色预警：

- 当前库存还能销售
- 预计不足 7 天
- 建议尽快调货

橙色缺码预警：

- 近 90 天有销售记录
- 某尺码库存已经为 0
- 建议补齐尺码

绿色安全库存：

- 库存满足安全库存要求
- 无需处理

#### 调货建议

系统自动计算：

- 建议调货数量
- 总部可调数量
- 剩余缺口数量

系统根据上述结果生成调货建议，供门店和总部进行补货、调拨或采购决策。

### 3. 高库存预警

#### 功能目标

系统用于发现库存积压商品，避免库存长期占压资金。

#### 数据来源

客户上传：

- 当前库存表
- 近 365 天销售表

#### 分析结果

系统计算：

- 年销量
- 日均销量
- 当前库存
- 预计消化天数

#### 预警等级

正常库存：

- 预计 100 天内可销售完成

高库存预警：

- 预计 100-200 天才能销售完成
- 建议关注销售情况

库存积压预警：

- 预计超过 200 天才能销售完成
- 建议促销、调货或减少采购

- 黄色预警数量

- 积压库存数量
- 建议调货总量

- 预警状态

#### 缺码预警表

显示字段：

- 商品
- 尺码
- 近 90 天销量
- 当前库存
- 总部库存
- 状态

#### 高库存预警表

显示字段：

- 商品
- 当前库存

- 日均销量

- 缺码预警

## 五、客户确认事项

请客户确认以下内容：

- 系统第一阶段以库存风险分析和结果导出为核心。
- 低库存、缺码和高库存预警规则按本文档执行。
- 企业微信自动提醒、AI 预测和自动补货建议不在第一阶段交付范围内。
- 如后续调整业务规则，以双方确认后的补充需求为准。
