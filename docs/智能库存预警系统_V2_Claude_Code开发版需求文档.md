# 智能库存预警系统 V2 Claude Code 开发版需求文档

## 一、系统版本与架构原则

项目名称：Inventory Warning System

目标版本：V2

当前系统架构已经采用：

```text
Data Source
↓
Standard Data Layer
↓
Warning Engine
↓
Result UI
```

后续所有功能必须基于统一标准数据层开发，并符合当前项目架构设计。

核心原则：

```text
Excel 模式
=
数据库模式
=
统一预警引擎
```

即：

```text
数据源
↓
标准数据层
↓
预警计算
↓
结果展示
```

禁止为 Excel 模式和数据库模式分别实现两套预警逻辑。所有库存预警计算必须共用同一个 Warning Service。

## 三、低库存预警模块

### 1. 数据来源

Excel 模式：

```text
销售表
库存表
总部库存表
长周期到货表（可选）
```

数据库模式：

```text
销售数据
库存数据
在途库存
总部库存表（人工上传）
长周期到货表（可选）
```

### 2. 标准字段

低库存预警引擎至少需要以下标准字段：

```text
商品编码
商品名称
尺码
近7天销量
006仓库存
系统已有在途库存
总部库存
长周期到货数量（可选）
```

字段命名可在标准数据层中映射，但进入 Warning Service 前必须统一。

### 3. 计算规则

当前可用量：

```text
当前可用量 = 006仓库存 + 系统已有在途库存
```

日均销量：

```text
日均销量 = 近7天销量 ÷ 7
```

可售天数：

```text
可售天数 = 当前可用量 ÷ 日均销量
```

当日均销量为 0 时，不应产生除零错误。此类数据默认不触发红色或黄色低库存预警，可按安全或无近期销售处理。

### 4. 预警规则

红色预警：

```text
近7天销量 > 0
AND
当前可用量 <= 0
```

黄色预警：

```text
近7天销量 > 0
AND
当前可用量 > 0
AND
可售天数 < 7
```

绿色安全库存：

```text
可售天数 >= 7
```

### 5. 调货计算

目标库存：

```text
目标库存 = 日均销量 × 7
```

建议调货量：

```text
建议调货量 = max(0, 目标库存 - 当前可用量)
```

总部可调数量：

```text
总部可调数量 = min(总部库存, 建议调货量)
```

剩余缺口数量：

```text
剩余缺口数量 = max(0, 建议调货量 - 总部可调数量)
```

## 四、缺码预警模块

### 1. 分析周期

```text
近90天销量
```

### 2. 标准字段

缺码预警引擎至少需要以下标准字段：

```text
商品编码
商品名称
尺码
近90天销量
006仓库存
总部库存
```

### 3. 触发条件

```text
近90天销量 > 0
AND
006仓库存 <= 0
```

### 4. 预警状态

```text
橙色缺码预警
```

### 5. 不触发条件

```text
近90天销量 = 0
AND
库存 = 0
```

该场景表示近期无销售且无库存，不作为缺码预警。

## 五、高库存预警模块

高库存预警为独立模块，不接入 T+，全部采用上传分析。

### 1. 数据输入

```text
库存表
历史销售表（365天）
```

### 2. 标准字段

高库存预警引擎至少需要以下标准字段：

```text
商品编码
商品名称
当前库存
365天销量
```

### 3. 计算规则

年销量：

```text
年销量 = sum(365天销量)
```

日均销量：

```text
日均销量 = 年销量 ÷ 365
```

预计消化天数：

```text
预计消化天数 = 当前库存 ÷ 日均销量
```

当日均销量为 0 且当前库存大于 0 时，预计消化天数可按无限大或特殊值处理，并应归入库存积压预警。

### 4. 预警规则

正常库存：

```text
预计消化天数 <= 100
```

高库存：

```text
100 < 预计消化天数 <= 200
```

库存积压：

```text
预计消化天数 > 200
```

## 七、接口与服务逻辑

### 1. Auth Service

职责：

- 用户登录校验
- 密码哈希与验证
- 当前登录用户解析
- 角色与状态校验
- 管理员用户管理操作

### 2. Warning Service

职责：

- 接收标准数据层输出
- 执行低库存预警计算
- 执行缺码预警计算
- 执行高库存预警计算
- 输出统一结果结构供页面展示和 Excel 导出

### 3. Data Source Adapter

职责：

- Excel 数据读取
- 数据库数据读取
- 字段映射
- 数据清洗
- 输出统一标准数据结构

## 九、开发约束

必须保持：

- Excel 模式和数据库模式共用统一标准数据层。
- Excel 模式和数据库模式共用同一个 Warning Service。
- 业务规则集中在服务层，不分散到页面模板中。
- 页面只负责展示结果和触发导出。
- 权限控制必须覆盖页面入口和后端接口。

禁止：

- Excel 一套逻辑，数据库一套逻辑。
- 在页面模板中直接写核心预警计算。
- 普通用户访问用户管理或系统设置接口。
- 忽略日均销量为 0 时的除零处理。
