# 畅捷云自建应用对接操作文档

本文档说明当前库存预警系统如何对接畅捷云 T+Cloud / tplus OpenAPI 的自建应用模式，以及你需要手动填写哪些配置。

## 1. 当前代码采用的模式

当前系统已经切换为：

```text
自建应用模式
```

不再依赖应用入驻 OAuth 授权码流程。

当前 token 流程是：

```text
畅捷云每 10 分钟推送 appTicket
        ↓
系统接口 /tplus/message/callback 接收并缓存 appTicket
        ↓
系统用 appTicket + certificate 调 generateToken
        ↓
拿到 accessToken
        ↓
业务接口请求头使用 openToken
```

自建应用获取 token 的接口是：

```text
https://openapi.chanjet.com/v1/common/auth/selfBuiltApp/generateToken
```

## 2. 畅捷云后台需要配置什么

在畅捷云开放平台的自建应用后台，需要配置消息订阅。

### 2.1 消息接收地址

填写：

```text
https://66f17b6b.r28.cpolar.top/tplus/message/callback
```

注意不是：

```text
https://66f17b6b.r28.cpolar.top/tplus/oauth/callback
```

`/tplus/oauth/callback` 是之前应用入驻 OAuth 模式用的，现在自建应用主要用 `/tplus/message/callback`。

### 2.2 消息秘钥
1234567812345678

按畅捷云后台要求填写或生成。

当前代码目前只接收和保存 `appTicket`，没有做消息签名校验。如果畅捷云要求必须校验签名，后续需要根据它的签名规则再补校验逻辑。

### 2.3 管理员授权

自建应用需要管理员授权。授权后会拿到：

```text
certificate
```

这个值要填到系统 `.env` 文件里。

## 3. 你需要手动填写的 .env 配置

文件位置：

```text
D:\photo\inventory-warning-system\.env
```

当前需要重点填写这些项：

```env
TPLUS_API_BASE_URL=业务接口基础地址
TPLUS_AUTH_BASE_URL=https://openapi.chanjet.com
TPLUS_AUTH_MODE=self_built
TPLUS_APP_KEY=你的开放平台AppKey
TPLUS_APP_SECRET=你的开放平台AppSecret
TPLUS_CERTIFICATE=管理员授权后获得的加密证书
TPLUS_APP_TICKET=
TPLUS_APP_TICKET_MAX_AGE_SECONDS=1500
```

### 3.1 TPLUS_API_BASE_URL

这是业务接口的基础地址。

现在 `.env` 里还是占位值：

```env
TPLUS_API_BASE_URL=https://api.example.com
```

需要改成畅捷云 T+Cloud 业务接口实际基础地址。

如果业务接口完整路径类似：

```text
https://openapi.chanjet.com/tplus/api/v2/inventory/Query
```

那可以配置：

```env
TPLUS_API_BASE_URL=https://openapi.chanjet.com
```

如果畅捷云给你的业务接口基础域名不同，以畅捷云实际文档为准。

### 3.2 TPLUS_AUTH_BASE_URL

认证接口基础地址，保持：

```env
TPLUS_AUTH_BASE_URL=https://openapi.chanjet.com
```

### 3.3 TPLUS_AUTH_MODE

必须是：

```env
TPLUS_AUTH_MODE=self_built
```

这表示系统使用自建应用模式。

### 3.4 TPLUS_APP_KEY

填写开放平台应用的 AppKey：

```env
TPLUS_APP_KEY=真实AppKey
```

不能保持：

```env
TPLUS_APP_KEY=YOUR_APP_KEY
```

### 3.5 TPLUS_APP_SECRET

填写开放平台应用的 AppSecret：

```env
TPLUS_APP_SECRET=真实AppSecret
```

不能保持：

```env
TPLUS_APP_SECRET=YOUR_APP_SECRET
```

### 3.6 TPLUS_CERTIFICATE

填写管理员授权后获得的加密证书：

```env
TPLUS_CERTIFICATE=真实certificate
```

自建应用获取 token 必须有这个值。

### 3.7 TPLUS_APP_TICKET

一般留空：

```env
TPLUS_APP_TICKET=
```

正常情况下，畅捷云会每 10 分钟调用：

```text
POST /tplus/message/callback
```

系统会自动保存最新的 `appTicket`。

只有临时测试时，才建议手动填一个未过期的 `appTicket`：

```env
TPLUS_APP_TICKET=t-xxxxxxxx
```

`appTicket` 有效期通常是 30 分钟，过期后需要新的。

### 3.8 TPLUS_APP_TICKET_MAX_AGE_SECONDS

当前配置：

```env
TPLUS_APP_TICKET_MAX_AGE_SECONDS=1500
```

含义是系统只使用 25 分钟内收到的 `appTicket`，避免拿快过期或已过期的 ticket 去换 token。

## 4. 代码里每个接口做什么

### 4.1 app/routers/tplus_oauth_router.py

这个文件现在有两个路由。

#### POST /tplus/message/callback

这是自建应用消息接收接口。

畅捷云会把 `appTicket` 推送到这里。

代码会做三件事：

```text
读取请求 query 参数和 JSON body
        ↓
从里面提取 appTicket
        ↓
保存到 outputs/tplus_app_ticket_cache.json
```

畅捷云后台的消息接收地址应该填这个接口的公网地址：

```text
https://66f17b6b.r28.cpolar.top/tplus/message/callback
```

#### GET /tplus/oauth/callback

这是之前应用入驻 OAuth 模式用的授权回调。

当前自建应用模式下不是主要入口，可以先保留，不影响系统。

### 4.2 app/data_sources/tplus_openapi_source.py

这是 T+ OpenAPI 客户端核心文件。

关键方法如下。

#### get_access_token()

业务接口调用前都会先走这个方法。

逻辑：

```text
先读 token 缓存
        ↓
如果 access_token 没快过期，直接用缓存
        ↓
如果过期或快过期，看 TPLUS_AUTH_MODE
        ↓
如果是 self_built，就用 appTicket + certificate 调 generateToken
```

#### generate_self_built_token(app_ticket, certificate)

调用自建应用 token 接口：

```text
/v1/common/auth/selfBuiltApp/generateToken
```

请求头：

```text
appKey
appSecret
Content-Type: application/json
```

请求体：

```json
{
  "appTicket": "t-xxxx",
  "certificate": "xxxx"
}
```

#### save_app_ticket(payload)

保存畅捷云推送来的 `appTicket`。

缓存文件：

```text
outputs/tplus_app_ticket_cache.json
```

#### _write_cached_token(payload)

保存 token。

缓存文件：

```text
outputs/tplus_token_cache.json
```

保存内容包括：

```json
{
  "access_token": "...",
  "refresh_token": "...",
  "access_token_expires_at": 1234567890,
  "refresh_token_expires_at": 1234567890,
  "org_id": "...",
  "user_id": "...",
  "app_name": "...",
  "scope": "...",
  "sid": "...",
  "updated_at": 1234567890
}
```

自建应用接口返回的是 camelCase，例如：

```text
accessToken
refreshToken
expiresIn
refreshExpiresIn
orgId
userId
appName
```

代码会统一转换成内部 snake_case 字段。

### 4.3 业务接口请求头

业务接口请求时，代码会带：

```text
openToken: access_token
```

如果缓存里有 `sid`，还会带：

```text
Cookie: sid=xxx
```

## 5. 运行步骤

### 5.1 启动 cpolar

确保公网地址可访问：

```text
https://66f17b6b.r28.cpolar.top
```

如果 cpolar 地址变化，必须同步修改畅捷云后台的消息接收地址。

### 5.2 启动系统

在项目目录运行：

```bash
uvicorn app.main:app --reload
```

如果使用虚拟环境，先激活：

```powershell
.\.venv\Scripts\Activate.ps1
```

### 5.3 测试消息接收接口

本地可以访问：

```text
http://127.0.0.1:8000/tplus/message/callback
```

但畅捷云不能访问你的 `127.0.0.1`。

畅捷云后台必须配置公网地址：

```text
https://66f17b6b.r28.cpolar.top/tplus/message/callback
```

### 5.4 等待畅捷云推送 appTicket

畅捷云正常会每 10 分钟推送一次 `appTicket`。

收到后，系统会生成：

```text
outputs/tplus_app_ticket_cache.json
```

如果没有这个文件，说明系统还没收到推送，或者消息接收地址没有配置成功。

### 5.5 触发库存分析

当你点击系统里的数据库分析或 T+ 数据分析时：

```text
系统读取 appTicket
        ↓
读取 TPLUS_CERTIFICATE
        ↓
调用 generateToken
        ↓
拿 accessToken 调 T+ 业务接口
```

## 6. 常见问题

### 6.1 提示未找到 appTicket

常见原因：

```text
畅捷云后台没有配置消息接收地址
cpolar 地址变了
系统没有启动
畅捷云还没推送 appTicket
appTicket 缓存已超过 25 分钟
```

处理：

```text
确认系统正在运行
确认 cpolar 地址可访问
确认畅捷云后台填的是 /tplus/message/callback
等待下一次 appTicket 推送
```

临时测试可以手动填：

```env
TPLUS_APP_TICKET=t-xxxx
```

### 6.2 提示缺少 TPLUS_CERTIFICATE

说明 `.env` 没填：

```env
TPLUS_CERTIFICATE=
```

需要把管理员授权后获得的 certificate 填进去。

### 6.3 提示 AppKey/AppSecret 是占位值

说明 `.env` 还没改：

```env
TPLUS_APP_KEY=YOUR_APP_KEY
TPLUS_APP_SECRET=YOUR_APP_SECRET
```

必须换成真实值。

### 6.4 业务接口 401 或 403

常见原因：

```text
accessToken 过期
appTicket 过期
certificate 不对
AppKey/AppSecret 不对
申请的接口权限不够
业务接口基础地址 TPLUS_API_BASE_URL 不对
```

处理顺序：

```text
先确认 TPLUS_APP_KEY / TPLUS_APP_SECRET / TPLUS_CERTIFICATE
再确认 appTicket 是否刚收到
再确认申请了对应查询类接口权限
最后确认 TPLUS_API_BASE_URL
```

## 7. 你现在最少需要准备的内容

你需要从畅捷云后台拿到或配置：

```text
1. AppKey
2. AppSecret
3. certificate
4. 消息秘钥
5. 消息接收地址
```

你需要手动写进 `.env` 的是：

```env
TPLUS_API_BASE_URL=真实业务接口基础地址
TPLUS_AUTH_BASE_URL=https://openapi.chanjet.com
TPLUS_AUTH_MODE=self_built
TPLUS_APP_KEY=真实AppKey
TPLUS_APP_SECRET=真实AppSecret
TPLUS_CERTIFICATE=真实certificate
TPLUS_APP_TICKET=
TPLUS_APP_TICKET_MAX_AGE_SECONDS=1500
```

你需要填到畅捷云后台的是：

```text
消息接收地址：https://66f17b6b.r28.cpolar.top/tplus/message/callback
消息秘钥：按畅捷云后台生成或填写
```

如果 cpolar 地址变化，上面两个地方都要同步检查：

```text
畅捷云后台消息接收地址
本系统是否能被公网访问
```
